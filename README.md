# Alfa Beach — arquivos do site

Este pacote contém os arquivos-base para edição e manutenção da landing page Alfa Beach.

## Estrutura
- `index.html`: página estática demonstrativa com seções comerciais, galeria, avaliações, informações, localização e formulário de consulta.
- `styles.css`: layout responsivo.
- `script.js`: menu mobile, galeria ampliável, formulário de consulta e links WhatsApp.
- `src/PousadaContent.ts`: conteúdo centralizado em TypeScript, correspondente ao arquivo de configuração usado no projeto Floot.

## Importante
- WhatsApp oficial configurado: `+55 71 99184-3800`.
- O botão “Como chegar” aponta para o link de Maps fornecido e aparece apenas na seção de localização.
- As imagens deste pacote são marcadores visuais/ilustrativos; substitua por fotografias reais autorizadas da Alfa Beach antes da publicação.
- Os trechos de avaliações e a nota pública precisam ser conferidos e ter as permissões de reprodução confirmadas.
- Este ZIP não publica o site nem inclui o ambiente interno do Floot, dependências instaladas ou os arquivos binários das imagens hospedadas na plataforma.
